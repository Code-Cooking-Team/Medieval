# Building LOD benchmark (#10)

Stakewall, Barracks, Wood Camp, and Guildhall use the shared instance renderer and resolve their glTF levels by the exported node names `lod_near` and `lod_far`. The far meshes use simplified indices baked into the assets. They reuse the original vertex data, materials, and node transforms. The blueprints retain their original tile grids.

| Building | Near triangles | Far triangles |
| --- | ---: | ---: |
| Stakewall, main post | 26 | 22 |
| Stakewall, all optional stakes present | 268 | 152 |
| Barracks | 4,659 | 1,544 |
| Wood Camp | 4,142 | 1,390 |
| Guildhall | 5,024 | 1,768 |

The four buildings switch to far at 100 tiles and return to near below 90 tiles. Stakewall applies the same seed to both levels. It rotates and scales the main post and includes the same subset of the 11 optional stakes at their original transforms.

Stakewall also has a third level, `lod_very_far`, at 160 tiles. It returns to the far mesh below 144 tiles. The third level uses a single capped triangular post with 6 vertices and 8 triangles. It keeps the seeded main-post rotation and height. The post is slightly tapered. Bases overlap in straight runs, while the tips can show small gaps. Diagonal runs can have gaps along the full height. The optional stakes and their shadows disappear at this level. The measurements and screenshots below predate the third level.

## Browser fixture

```sh
bun run dev
CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  node benchmarks/run-buildings.mjs docs/benchmarks/buildings-lod 4
```

The fixture uses the same camera paths, 800 × 600 viewport, seeds, directional shadow map, and renderer settings for every layout. Each populated layout contains 100 buildings. The fixture removes actor point lights so all layouts use the same lighting. Chrome uses ANGLE SwiftShader. Scene totals include shadow submissions, the ground, and the fullscreen output pass. The empty scene contributes 2 calls and 3 triangles per frame.

The browser checks compare every submitted instance against the expected geometry and transform in near, far, and mixed views. They cross each threshold in both directions, exercise click and box selection and individual outlines, and compare rotated previews against the committed instances at both distances. They also round-trip saves and verify instance slots and picking proxies after removal and replacement. A separate production-preview check loaded a four-building save generated by the pre-change checkout (`f794c35`) through the game's **Load** button and confirmed actor IDs, positions, rotations, and seeds.
